## metalcloud-cli server-instance config-example

Print an example server instance create configuration

### Synopsis

Print an example configuration that can be edited and passed to
'server-instance create --config-source'.

Examples:
  metalcloud-cli server-instance config-example > server-instance.json
  metalcloud-cli inst config-example -f yaml

```
metalcloud-cli server-instance config-example [flags]
```
